# 字体安装

主文件使用原模板的 `fontset=windows` 配置。编译前请在操作系统中安装所需字体：

| 用途 | 字体名称 |
| --- | --- |
| 中文正文 | SimSun（宋体） |
| 中文标题 | SimHei（黑体） |
| 中文楷体 | KaiTi（楷体） |
| 中文等宽文字 | FangSong（仿宋） |
| 摘要等隶书文字 | LiSu（隶书） |
| 西文正文 | Times New Roman |
| 西文无衬线文字 | Arial |
| 代码 | Courier New |

macOS 可双击字体文件，通过“字体册”安装；安装后重新编译。
Windows 可通过字体文件右键菜单安装。请使用具有相应使用权限的字体文件。

本目录可保存本地字体，但字体二进制文件不纳入 Git 仓库。
仅将字体复制到此目录不会使 XeLaTeX 自动加载它们；模板按系统字体名称查找字体。
`STXinwei` 未被当前主文件使用，无需为本模板额外安装。
