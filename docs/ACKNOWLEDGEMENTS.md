# 模板来源与资源

## GMCMthesis

本项目以原 GMCMthesis 模板及其 `example-color.tex` 为基础整理。
`gmcmthesis.cls` 文件头保留了 LaTeX Studio、andy123t 等原作者信息；
类文件、`gmcm.bst`、原始示例及封面资源保留原内容。

## CUMCM 模板

分文件章节组织和部分宏包、代码样式、程序示例参考了
`CUMCM-Latex-template-2026-06-12`，其中部分示例经过适配。
该来源提供的 MIT 许可及版权信息见 [CUMCM-MIT.txt](licenses/CUMCM-MIT.txt)，
用于保留这些移植内容的来源声明。

## 其他资源

- `contest/` 保存随原模板提供的比赛资料，文件内容保持原样。
- 图片与封面资源保留原文件；四张示例 EPS 另附对应的矢量 PDF，便于编译。
- 字体由使用者在本机安装，仓库仅提供字体说明。

各来源文件保留自身的版权和许可信息；上述 MIT 许可不表示为所有第三方资料重新授予许可。
